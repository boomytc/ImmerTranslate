站点名单

默认所有网站都可以翻译。永不翻译（黑名单）里的来源不会插入双语节点，扩展图标和段落快捷键都不会。始终翻译（白名单）可选：打开该来源时自动翻译。同一来源两边都有时，以永不翻译为准。只填域名则同时匹配 http 与 https；填完整网址则只匹配该协议和主机（含端口）。子域名不会跟着生效。

      阅读样式

      改字号、对比度或显示方式会立刻写入本机。已经打开、并且已经译过的页面会马上换样式，不用整页刷新。名单的加入和移除也同样立即保存。底部「保存」会再写一遍这些项，并保存上面的密钥和快捷键。

      额度 / 引擎说明（明文）
      • 未填 API Key 时走 mock，译文形如 ⟦原文⟧，无额度限制。
      • 填 Key 后走所选协议；消耗以你自备 API 提供商账单为准。本扩展不设日限墙、不逼付费。
      • 段落快捷键存在本机设置里，默认 Alt+T。
      • 黑名单为空时所有网站都可以翻译。列入永不翻译的来源不会插入译文。
      • 译文字号、对比度，以及双语对照或仅译文，都只存在本机。
